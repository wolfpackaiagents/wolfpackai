# Support Knowledge Base

## Password Reset
To reset a password, navigate to Settings > Security > Reset Password.
The user must have access to their registered email.
If the email is not accessible, an admin override is required.

## Account Lockout
After 5 failed login attempts, the account is locked for 30 minutes.
Admins can unlock accounts from the Admin Panel > Users > Unlock.

## Billing
Standard plans are billed monthly. Enterprise plans are billed annually.
Refunds are processed within 5-10 business days.
Contact billing@support.com for disputes.

## API Access
API keys can be generated from Settings > Developer > API Keys.
Rate limit: 1000 requests per hour for standard plans.
Rate limit: 10000 requests per hour for enterprise plans.
