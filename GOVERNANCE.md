# Governance

Wolfpack AI is maintained by Alvaro Brito during the beta period.

## Decision making

The maintainer makes final decisions on roadmap, architecture, releases, and merging contributions. Public issues and Pull Requests are the preferred place for technical discussion.

## Maintainer responsibilities

The maintainer reviews contributions, protects project security, manages releases, and keeps the public roadmap and documentation accurate.

## Contribution review

All changes enter through Pull Requests. The maintainer reviews the scope, tests, documentation, compatibility, and security impact before merging.

## Releases

Only the maintainer can initiate releases. Release workflows run from `main` and publish artifacts after validation. See [RELEASING.md](RELEASING.md).

## Governance changes

Changes to this document require a Pull Request and maintainer approval.
